# Demo data

`demo-backup.json` is a **completely fictional** backup of about six weeks of spending (a salary, rent, subscriptions, a
Goa trip tagged `#goa`, weekday lunches tagged `#work`, three budgets and six recurring entries). It's what the README
screenshots were taken from.

To load it on your own device or emulator:

1. Install the app.
2. Copy `demo-backup.json` onto the phone (for example into *Downloads*).
3. **Settings → Restore from backup**, choose the file, and confirm **Replace**.

This replaces everything in the app, so don't do it on a phone that holds real data you haven't backed up.

The dates are fixed (October 1 to November 18, 2026), so the "this month" screens look best if the phone's date is
in that window.
